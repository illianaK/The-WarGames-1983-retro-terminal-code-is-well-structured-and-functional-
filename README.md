Generate the Android APK
Copy your live GitHub website link.

Open PWABuilder.com.

Paste your URL into the input field and click Start.

Once the site finishes analyzing your page, click the Package for Store button under the Android card.
Click Generate to download your compiled .apk file directly to your computer or phone.

Install the App on Android
Transfer the downloaded .apk file to your Android phone.
Tap the file to open it.

If prompted, toggle "Allow installation from unknown sources" in your phone's security settings.
Tap Install to launch W.O.P.R. as a standalone Android application.
